# 일본 주요 섬 · 지방 · 도도부현 타일 지도

일본의 47개 도도부현을 실제 지리 위치에 맞춰 배열한 타일 지도입니다.
의존성 없는 단일 HTML 파일(인라인 SVG + 바닐라 JS)이라 정적 호스팅에 그대로 올라갑니다.

## 읽는 법

| 표현 | 의미 |
|---|---|
| 타일 색 | 8개 지방 (홋카이도 / 도호쿠 / 간토 / 주부 / 긴키 / 주고쿠 / 시코쿠 / 규슈·오키나와) |
| 점선 경계 | 섬 단위 (혼슈 / 홋카이도 / 시코쿠 / 규슈 / 오키나와) |
| 都 · 道 · 府 배지 | 도쿄도, 홋카이도, 오사카부·교토부. 나머지 43곳은 모두 현(県) |
| 타일 hover / tap | 하단 패널에 지방 · 섬 · 주요 도시 표시 |

타일 격자를 쓴 이유는 오사카부나 가가와현처럼 면적이 작은 곳도 홋카이도와 동일한 크기로 읽히게 하려는 것입니다.
면적 비례가 필요하면 GeoJSON 기반 윤곽선 지도로 교체하면 됩니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 배포

GitHub Pages를 쓰는 경우, 푸시 후 저장소 **Settings → Pages** 에서
Source 를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)` 로 지정하면 됩니다.
`.nojekyll` 파일이 포함되어 있어 Jekyll 전처리는 건너뜁니다.

배포 주소는 `https://<GitHub-사용자명>.github.io/<저장소명>/` 형태가 됩니다.

## 파일

```
index.html    지도 본체 (단일 파일, 외부 의존성 없음)
.nojekyll     GitHub Pages Jekyll 우회
README.md
```
